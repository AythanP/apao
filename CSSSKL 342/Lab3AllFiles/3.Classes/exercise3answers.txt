Q: Is there a problem with the fact that SquareContainer.h defines two classes?

Q: Can you put an implementation of a method inside a .h file in C++? What is the purpose of doing so?
A: Yes. The purpose of doing so is to implement short functions that don't need to be in their own implementation file.
